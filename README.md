# 领取会员 · EchoMusic 插件

把 EchoMusic 在 2.3 版移除的「**领取畅听会员 / 升级概念会员**」功能恢复回来。

用的是软件自带的官方接口（`ctx.kugou.user.claimDayVip` / `upgradeDayVip`），
和 2.2.8 内置版本里点到的是同一个功能。签名、鉴权、风控验证全部由 EchoMusic 自己完成，
插件只负责点这两个按钮。

## 安装

**方式一：作为插件源添加（可远程安装、可自动更新）**

1. 打开 EchoMusic → **插件管理** → 切到「**在线插件**」
2. 添加插件源，地址填：

   ```
   https://github.com/xiyingruyi/echomusic-claim-vip
   ```

3. 在列表里找到「**领取会员**」，点安装，然后把开关打开。

**方式二：下载 zip 拖拽安装**

1. 从 [Releases](https://github.com/xiyingruyi/echomusic-claim-vip/releases) 下载 `claim-vip.zip`
2. 打开 EchoMusic → **插件管理** → 把 zip **拖进页面**（会提示「松开安装插件」）
3. 在列表里找到「**领取会员**」，把开关打开。

## 使用

插件有**两个入口**，任选其一：

- **标题栏礼物图标** —— 标题栏右侧点礼物图标弹出面板（推荐）
- **设置 → 插件 → 领取会员** —— 同一个面板

面板内容：

- 顶部显示今天两个会员的状态（已领取 / 未领取、已升级 / 未升级）
- **领取畅听会员** —— 领每日畅听 VIP
- **升级概念会员** —— 把今天的畅听会员升级为概念会员
- **登录后自动领取** —— 打开后每次登录 EchoMusic 自动领取并升级

两个会员每天各一次，按北京时间 0 点重置。领过之后按钮会置灰，这是正常现象。

## 与「自动领取会员」插件的冲突

如果你同时装了 `echo-auto-vip`（自动领取会员），两者功能重合，
建议**只开一个**，把另一个的开关关掉即可（不用卸载）。
两个同时开着时登录会各请求一次，第二次会被服务器拒绝，只会多弹一次无意义的提示。

## 兼容性

- 需要 EchoMusic `>= 2.2.6-beta.9`
- 在 2.2.8-beta.5（最后一个内置该功能的版本）与 2.3.2-beta.16 上验证过 API 与运行时契约
- 标题栏入口需要 `>= 2.3.2-beta.4`；更低版本会自动回退，只保留设置页入口

## 权限

只声明了一项能力：

| 能力 | 用途 |
| --- | --- |
| `kugouApi` | 调用酷狗官方接口领取/升级会员 |

不读取本地文件、不发起自定义网络请求、不写入插件数据以外的任何位置。

## 文件结构

```
manifest.json       插件清单
index.js            插件主体（ESM，导出 activate / deactivate）
icon.svg            插件图标
echo-plugins.json   插件源索引（供 EchoMusic「在线插件」读取）
scripts/build.sh    打包发布 zip：./scripts/build.sh
```
